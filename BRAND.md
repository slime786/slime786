# SLIME786™ Brand Standard

**Master brand:** SLIME786™  
**Descriptor:** Products, technology & independent ventures.

SLIME786 is the creator and portfolio brand used across the GitHub account and associated projects.

## Brand usage

Use **SLIME786™** in public-facing headings, documentation, product credits and portfolio references.

Use `slime786` only where a platform or technical context uses the GitHub username or lowercase identifier.

Do not use alternative public forms such as `Slime786`, `SLIME 786`, `Slime 786` or `SLIME-786`.

The ™ symbol denotes trademark use; it does not represent a registered trademark. Do not use ® unless registration has been granted in the relevant jurisdiction.

## Portfolio endorsements

Use the endorsement that matches the project:

- **A SLIME786™ product.** — software and product projects intended to solve a user problem.
- **A SLIME786™ experiment.** — intentionally exploratory or paused concepts.
- **A SLIME786™ game.** — original game projects.
- **A SLIME786™ venture.** — standalone consumer or business brands.

The individual project name remains primary. SLIME786 should endorse the project rather than replace a strong standalone product or business name.

## Repository naming

Prefer lowercase kebab-case for new repository names.

Examples:

- `guard`
- `handoff`
- `why`
- `rewind`
- `called-it`
- `life-admin`
- `iron-vultures`
- `mofries`
- `slimes-collectables`
- `decision-coin`

Existing repositories do not need to be renamed solely for visual consistency when doing so could affect deployments, integrations or existing links.

## README hierarchy

A repository README should normally follow this order:

1. Product or business name.
2. SLIME786 endorsement.
3. One concise statement of what the project does.
4. Current status.
5. Product, technical or operating detail.
6. Standard SLIME786 footer.

## GitHub metadata

Repository descriptions should be factual, concise and consistent with the README. Avoid describing planned features as already shipped.

Use relevant repository topics where useful, typically 4–6 focused terms rather than a long keyword list.

## Ownership and attribution

SLIME786 is the portfolio/creator brand. Copyright attribution remains with the applicable creator or rights holder unless a legal entity or written assignment changes that position.

Third-party names, trademarks, assets and licences remain subject to their respective owners and terms.

## Brand principle

**One parent identity, distinct product brands.**

SLIME786 provides the consistent signature across the portfolio while each product, game or venture keeps the name best suited to its audience.
