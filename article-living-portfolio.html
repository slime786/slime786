BUILDING / WEB

A portfolio should feel alive.

MOHEEN MAHMOOD · LONDON · 4 MIN READ

I did not want this website to be a static page containing a name, a few boxes and a contact link.

The idea became a personal command centre: part portfolio, part notebook, part market dashboard and part playground. The live information gives it movement. The journal gives it a point of view. GitHub connects it to things I actually build. The rocket game adds something deliberately unnecessary and fun.

That combination matters to me because a personal website can show how someone thinks, not only what they have completed.

There is also a useful constraint: this site is intentionally deployable as a static GitHub Pages project. That means features should fail gracefully and should not pretend to have server-side capabilities that do not exist.

The website will keep changing. That is the point. A portfolio can be a finished presentation, but it can also be an evolving record of curiosity.
