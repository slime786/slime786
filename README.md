# V9.3 — Moheen // Arcade

Builds directly on V9.2.

New arcade:
- Space Boost 2.0: shield, energy pickups, variable asteroid sizes, A/D controls, pause, XP and persistent high score
- Orbital Defender: click/tap wave survival game
- Signal Decode: progressively harder memory/logic sequence game
- Arcade mission selector
- local Arcade XP and mission-completion profile
- optional sound toggle
- responsive mobile layout

Everything runs client-side on GitHub Pages. Scores and XP are stored only in the visitor's browser with localStorage.

Upload every file in this ZIP to the root of `main`, replacing matching files.
