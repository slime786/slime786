Premium responsive portfolio for Moheen Mahmood.

## Included
- Editorial/futuristic responsive design
- Custom mouse cursor on desktop

## Live data note
Crypto prices are requested client-side from CoinGecko and refresh every 60 seconds. The site does not embed a private API key.

For exchange-grade realtime stock quotes, use a licensed market-data provider. Alpha Vantage documents realtime/15-minute delayed US market data and notes that realtime US quotes are premium/regulated. A server-side proxy is preferable to exposing API credentials in browser JavaScript.
