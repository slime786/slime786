## Housekeeping standard

Each active repository should have:

1. A short README that states purpose, status, quick start and folder map.
2. One obvious application entry point.
3. Generated/build output excluded from Git.
4. Historical material grouped under `docs/`, `archive/` or `backups/` where practical.
5. No secrets, production credentials or personal customer data.
6. CI that checks the project without creating unnecessary artifacts.
7. Clear deployment/security warnings for local-only MCP or pre-launch services.
