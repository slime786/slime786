# Roll back to V9.3.1

Nothing in GitHub is permanently lost when you upload V10.

Fastest rollback:
1. Keep `moheen-mahmood-v9-3-1-STABLE-BACKUP.zip`.
2. Extract it.
3. In the GitHub repository, upload those files to the root of `main`, replacing matching files.
4. Commit with a message such as `Rollback to V9.3.1`.
5. Wait for GitHub Pages to redeploy and hard-refresh the site.

Your previous GitHub commits also remain in repository history, so V10 does not erase the old version.
